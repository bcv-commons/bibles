# bsb-global

Berean Standard Bible (BSB), German (Bernese) dialect edition, held under
`gt/bern1242/BSB/`.

**Licence:** Public Domain (BSB). Everything under this folder carries the
same licence.

**Layout**

```
gt/bern1242/BSB/txt/<BOOK>/<chapter>.txt
```

- `<BOOK>` is the USFM book code (GEN, EPH, JHN, JON, RUT).
- `<chapter>.txt` holds one chapter of text, with no leading zeros.
- Notes, footnotes, style guides and review files sit in the same book
  folders. They are kept as they are.
